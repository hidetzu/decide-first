# 0004 最初の画面には判定と「人間が決めること」だけを出す

- 日付: 2026-10-10
- 状態: 採用

## 決めたこと

- 最初の画面に出すのは次の 4 つだけ。
  1. Issue の識別（`owner/repo#N` とタイトル）
  2. 判定
  3. 「AIに渡す前に、人間が N つ決める必要があります。」
  4. decision の番号つきリスト
- check の ✓ / ✗ と evidence は「詳細を見る」（`<details>`）の中にだけ出す。

## 捨てたもの

- **大きな点数表示。** 「今渡していい / まだダメ」の判断が遅くなる。
- **最初から全 check を並べる表示。** 人間が数秒で判断できることを優先する。
