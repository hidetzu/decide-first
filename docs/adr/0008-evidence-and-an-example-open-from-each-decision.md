## 決めたこと

- **案 C を採る。** 「人間が決めること」の各項目の末尾に、開く手掛かりを置く。開くと、その項目の根拠と書き方の例が出る。
- **根拠に出してよいのは、出典が測った数値だけ。** 次の 3 つを必ず添える。
  - 出典
  - 対象の範囲（例: Copilot の PR 3,180 件）
  - 相関であること
- **出典に数値がない項目には、数値がないとそのまま書く。** 近い数値を借りてこない。
  - 例: Verification。Sayagh には検証方法の merge 率の差の報告がない（`docs/research.md`）。

## 捨てたもの

- **この Issue に「AI の理解しにくさ」の点数を付けること。** 測っていない数値になる（ADR 0002、`.claude/rules/evidence.md`）。
- **「このフォーマットならミスが X% 減る」と、画面に一括で出すこと。** 相関を因果として読ませてしまう。
- **案 A。** 根拠が、決めることから離れた奥に置かれる。
- **案 B。** 最初の画面が 1.5 倍の高さになる。ADR 0004（最初の画面は判定と決めることだけ）を崩す。

## 受け入れた代償

- 開かれなければ、数値は読まれない。
- 書き方の例の文言と根拠の文言は、人が読む文言なので、実装の前に別途決める。
